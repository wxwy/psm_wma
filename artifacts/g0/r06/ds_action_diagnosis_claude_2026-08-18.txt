3) 收敛后的嫌疑（排序）：
  A. 训练侧没学会正确的 vision→action 速度场（耦合弱+错）。SFT 放大耦合但方向错误 → 支持。
  B. 推理循环把耦合洗掉（unipc/共享 timestep/积分路径）。→ teacher-forced 探针可判。
  C. attention 对 action 位置的 condition 权重结构性地低（mROPE/稀释，非 mask）。→ 弱耦合与它相符但非主嫌。

4) 按判别力/成本排序的最小实验序列（每实验判据）：
  E0【已做】server 黑帧/场景/prompt 探针：action 对视觉/文本/场景均不敏感(≤0.02)，video 敏感(255)。
  E1【0成本】predictions.npz 量化耦合（已完成）：弱耦合实锤（0.055→0.158）。
  E2【判别力最高,离线】teacher-forced 探针（你的候选，评估见下）：单前向测 preds_action 速度场
    对 vision 的耦合。判据：
      - real/black vision 的 preds_action 差异显著 且 real 重建 MAE << black → 网络能路由 vision→action，
        问题在推理循环(B) 或 训练映射(A) 的子问题
      - 差异≈0 → 网络前向不能路由 → C 或 A，转 E4。
  E3【低成本】同 vision、不同 seed 的 action 输出：
      - 几乎不变 → action 输出不来自噪声积分（硬 bug，绕过 diffusion）
      - 显著变化 → action 确被去噪，但去噪器忽略条件（A/B）。
  E4【中成本】two_way full pass 挂 attention 钩子，统计 action query 对[text|vision|action]的权重质量：
      - vision 权重≈0 → C 实锤（mROPE/位置）
      - vision 权重正常但 preds_action 不变 → llm2action 速度头或训练(A)。

5) teacher-forced 探针评估：
  判别力 ★★★★★：直接测网络前向能否把 vision 路由到 action token 隐藏状态，不受采样/seed/积分干扰。
  关键点：必须测 preds_action（速度），不是最终 action（因为最终 action=积分结果，见 F1）。
  设计：固定 σ∈{0.1,0.3,0.5,0.7,0.9}（对齐 logitnormal 训练分布）；vision=真实slot0 vs 黑帧；
  xt_action=(1-σ)·x0_action+σ·noise；一次 denoise → 取 out["preds_action"]；比较 real/black 差异
  与相对 v_true=x0_action-noise 的 MAE。用 iter800 checkpoint + SFT config 的归一化 stats。
  成本：一次模型加载 + 数次前向。陷阱：σ 要覆盖训练分布；wam 模式 slot0 保持 clean；
  别只测 0.5。
