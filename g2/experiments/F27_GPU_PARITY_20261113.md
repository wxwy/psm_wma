## Performance caveat

- Historical baseline full 19-state F27 wall time: about 260 seconds, before the active 32-worker run.
- The experimental process was deliberately nice 19, concurrent with 32 production workers, and its 1,100-second cap covered only 15 states. These runs have *different contention* and *different priority*, so no end-to-end speedup or slowdown can validly be concluded from their wall times.
- Earlier same-process MaterialResolver microtests observed 4.35x local speedup for 12k source-bound samples on a real 2048x2048 sRGB texture and 87.5% smaller per-texture CPU cache, with exact source color/alpha evidence parity. This is not an end-to-end F27 speedup claim.
- GPU FP64 mesh kernel already works; further bottlenecks include CPU material/appearance work, compositing, GPU transfers and memory contention.
