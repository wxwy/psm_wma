## All-mask output: PASS, but zero token is NOT equivalent to Local absent downstream

At `local_evidence.py:151-152` the MLP output is multiplied by `has_valid`, so an H>0/all-mask sample produces an exact-zero Local token.

This is correct as a **readout-level inert value**, but Step 6 must not mistake it for a valid packed Local condition.

R07's downstream Local projection is:

`cosmos3_vfm_network.py:227-228`

```python
self.local_memory2llm = nn.Linear(..., bias=config.enable_input_bias)
self.local_memory_modality_embed = nn.Parameter(...)
```

and packing applies:

`cosmos3_vfm_network.py:958`

```python
packed_tokens_local = self.local_memory2llm(packed_tokens_local) + self.local_memory_modality_embed
```

Although these are function-preserving zero-initialized in R07, they are trainable. After training:

```text
readout token = 0
does NOT imply
packed Local condition = 0
```

because Linear bias and modality embedding may become nonzero.

Therefore **Step 6 has a hard requirement**:

> if `history_mask.any(dim=1) == False` for a sample, that sample must have Local **absent**, not merely a packed zero Local token.

This requirement applies both to:
- episode-start/all-mask samples at H>0;
- the H=0 no-history control.

Mixed batches must preserve this per-sample absence semantics.
