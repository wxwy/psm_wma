## HIGH-1 — `history_action` collides with an existing reserved native-Action field

### Finding

The new dataset returns the normalized R08 historical action under:

`cosmos_framework/data/generator/action/datasets/libero_lerobot_dataset.py:518`

```python
"history_action": action,
```

But `ActionTransformPipeline` already had a pre-existing special meaning for exactly this key:

`cosmos_framework/data/generator/action/utils/transforms.py:746-760`

```python
history_action = data_dict.pop("history_action", None)
num_history_actions = 0
if history_action is not None and isinstance(action, torch.Tensor):
    num_history_actions = history_action.shape[0]
    action = torch.cat([history_action, action], dim=0)
    action_length += num_history_actions

sequence_plan = build_sequence_plan_from_mode(
    ...
    num_history_actions=num_history_actions,
)
```

This transform file is unchanged between the pre-R08 submodule `10bc410` and `31983c5` (same Git blob `62dd8905612a56978a7f92022f5dc8643b47ef1e`). Therefore this is not newly introduced transform logic; the Step 2 dataset has accidentally reused an already-reserved field name.

### Impact

When `local_history_horizon > 0`, the intended Local evidence is silently consumed before any future LocalEvidenceEncoder can see it:

1. `history_action` is popped from the sample;
2. all H rows are prepended to the **native Action stream**;
3. `action_length` changes;
4. `num_history_actions` changes;
5. `SequencePlan` conditioning indexes change;
6. padded rows are also included because the native transform has no R08 `history_mask` semantics;
7. `ActionProcessor.preprocess_action()` then processes this modified native Action tensor.

This violates the frozen R08 boundary:

- R08 Step 2 should only construct Local evidence;
- historical action must not alter native Action targets/conditioning;
- native Vision/Action sequence semantics and mRoPE-related planning must remain unchanged.

Default `local_history_horizon=0` prevents baseline regression today, but the intended H>0 R08 path is incorrect.

### Required fix

Do **not** change the existing native `history_action` semantics in `ActionTransformPipeline`.

Use an R08/Local-specific key for the normalized evidence, for example:

- `local_history_action` (preferred), or
- another explicit Local-evidence-only name.

`history_action_raw` does not currently collide and can remain if desired, but naming both normalized/raw fields with a consistent Local prefix would reduce future ambiguity.

The future LocalEvidenceEncoder/readout must consume the Local-specific key. The existing native `history_action` feature remains untouched.

### Required regression acceptance

Add a permanent CPU test that runs an H>0 R08 sample through the real `ActionTransformPipeline` and proves:

- native current `action` content/length is identical to the same sample with R08 history disabled;
- `SequencePlan` native Action conditioning indexes/shape are unchanged;
- R08 Local historical action remains present under its Local-specific key after the transform;
- padding/mask do not enter the native Action stream.

This is the key closure test for HIGH-1.
