## HIGH-1 — R08 runtime parameters remain outside the optimizer-visible subtree

Current R08 registration in `omni_mot_model.py`:

```python
self.local_history_runtime = LocalHistoryRuntime(...)
```

This is an outer `OmniMoTModel` child module.

The actual generator optimizer implementation in `cosmos_framework/utils/generator/optimizer.py` explicitly does:

```python
net_params = dict(model.net.named_parameters())
...
if len(keys_to_select) > 0 and not any(key in pn for key in keys_to_select):
    p.requires_grad = False
    continue
```

The optimizer documentation in the same function also states that only parameters under the `net.` subtree are considered.

Thus:

```text
keys_to_select += ['local_history_runtime']
``

does not help if `local_history_runtime` is not under `model.net`.

The current unit test `test_edge_config_selects_only_r08_runtime_and_r07_local_parameters` does not catch this because it constructs synthetic runtime parameter names from `_runtime().named_parameters()` and applies substring matching manually. It does not invoke the real optimizer selector on the real model hierarchy.
