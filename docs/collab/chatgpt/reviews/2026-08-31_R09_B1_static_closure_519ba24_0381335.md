## Important design note

B1 currently selects encoder parameters into the optimizer while the frozen TTT detach contract means the Local TTT path supplies them no gradient.

That is consistent with the approved contract and correctly recorded as a fact, so it is **not** a B1-S failure. However, before long training/backend freeze, the project should explicitly decide whether:

- encoder is intentionally frozen-by-detach but left in optimizer for recipe symmetry, or
- encoder should be removed from the B1 optimizer allowlist.

Do not change this during B1-G smoke; keep the variable isolated.
