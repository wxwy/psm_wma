## Finding

### HIGH — selector-aware verifier trusts artifact selector instead of independently binding the frozen production recipe

`tools/g0/verify_r09_b2_p3_gpu_inventory.py` computes an allowed optimizer difference from the two backend records themselves:

```python
recurrent_keys = recurrent.get("selector", {}).get("keys_to_select", [])
ttt_keys = ttt.get("selector", {}).get("keys_to_select", [])
extra_keys = set(recurrent_keys) - set(ttt_keys)
return any(key in name for key in extra_keys)
```

This is not an independent production-selector check. An artifact can claim additional recurrent selector keys and thereby expand the verifier's recurrent-only optimizer / resolved-selector / optimizer-DCP allowlist. The artifact is the object being verified; its own selector fields cannot serve as the source of truth for what differences are permitted.

The request says the verifier reads the frozen production recipe and derives recurrent/TTT selector lists, but the submitted verifier does not do that.

The frozen production recipe at Gitlink `21d064f` defines the selector behavior directly:

- inherited Nano optimizer keys: `moe_gen`, `time_embedder`, `vae2llm`, `llm2vae`, `action2llm`, `llm2action`, `action_modality_embed`;
- recurrent/local-history path appends `local_memory2llm`, `local_memory_modality_embed`, and `local_history_runtime`;
- TTT path replaces `keys_to_select` with exactly `local_history_runtime.encoder`, `local_memory2llm`, `local_memory_modality_embed`.

Those production semantics must be independently derived or frozen by the verifier. They must not be inferred from the artifact under test.

## Required changes

1. Derive the expected recurrent and TTT selector key lists from the exact frozen production recipe/Gitlink used by the artifact, or encode an exact verifier-owned contract tied to the frozen source SHA. Do not trust `artifact[*].inventory.selector.keys_to_select` as the allowlist source.
2. Require each backend artifact selector list to equal its independently derived expected list exactly.
3. Use only the independently derived selector delta when explaining recurrent-only optimizer / resolved-selector / optimizer-DCP membership differences.
4. Keep TTT-only differences forbidden and keep model/buffer/DCP-model structural allowlists unchanged.
5. Add permanent negative regressions proving that mutating an artifact selector to add a broad key (for example `language_model`) cannot turn an otherwise forbidden recurrent-only difference into PASS.
6. Add a regression that an artifact selector list differing from the frozen production selector list makes the verifier fail.

No GPU rerun is needed for this fix. Re-verify the existing attempt-6 artifact only after the verifier contract is independently bound to the frozen production selector semantics.
