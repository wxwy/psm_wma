## HIGH-1 — presence must not be inferred from `state != 0`

Current implementation:

```python
present = mask.bool().any(dim=1) | state.ne(0).any(dim=1)
```

This improves the previous implementation, but it does not implement the frozen semantic contract robustly.

Presence means:

> this sample has established Local memory since the last explicit reset

It is not equivalent to:

> the latent tensor currently contains at least one nonzero floating-point element

A valid recurrent update can in principle produce an exactly-zero latent state. Presence must remain true if valid evidence was observed, regardless of the numerical latent value.

Therefore state-value inference can violate:

```text
once valid evidence establishes Local memory
-> later all-masked segments preserve local_present
-> only explicit reset clears local_present
```

### Required fix

Carry presence explicitly as part of backend state, e.g. conceptually:

```text
BackendState:
  latent [B,D]
  present [B]
```

or equivalent `state_in + present_in` API.

Required semantics:

- zero-init: present=false;
- valid evidence: present=true;
- masked evidence: present unchanged;
- segment carry: present carried exactly;
- selected reset: reset latent and present only where done=true;
- all-mask full window from zero-init: absent;
- all-mask segment after prior valid evidence: still present.

Do not derive presence from latent magnitude/value.
