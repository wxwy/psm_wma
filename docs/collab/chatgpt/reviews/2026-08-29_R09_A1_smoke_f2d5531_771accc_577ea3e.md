## HIGH-1 — R09 recurrent path bypasses `readout`, but `readout.*` is in the optimizer

Current A1 config:

```text
cosmos_framework/configs/base/experiment/action/posttrain_config/action_policy_libero_edge_all.py:188-195

local_history_runtime.encoder
local_history_runtime.recurrent_backend
local_history_runtime.readout
local_memory2llm
local_memory_modality_embed
```

But production runtime does:

```python
# cosmos_framework/model/generator/mot/local_evidence.py:244-249
if self.recurrent_backend is None:
    tokens = self.readout(evidence, history_mask)
    present = history_mask.bool().any(dim=1)
else:
    tokens, _, present = self.recurrent_backend.replay(evidence, history_mask)
```

So whenever R09 A is enabled, `self.readout` is not in the forward/loss graph.

This is also visible in the checkpoint evidence:

- all four `net.local_history_runtime.readout.mlp.*` tensors are selected;
- none appears in `changed_preexisting_names` after 100 optimizer steps.

The four selected readout tensors are therefore dead optimizer members under the submitted architecture.

This conflicts with the previously frozen A1 statement that the Local encoder/compressor/**readout**/adapter are the trainable scope and prevents the required Local-gradient proof from succeeding as written.

### Recommended minimal resolution

Preserve the current R09 dataflow and make the contract explicit:

```text
encoder -> recurrent_backend -> D_local token
```

Treat the R08 `StatelessLocalReplayReadout` as dormant/frozen compatibility state whenever an R09 backend is active.

Then amend the A1/R09-B scope to remove:

```text
net.local_history_runtime.readout.*
```

from the R09 optimizer allowlist, and explicitly freeze it.

This is the smallest change and keeps A/B single-variable if R09-B exposes the same `Backend.replay -> D_local token` interface.

Alternative: if a shared post-compressor readout is genuinely intended, redesign/wire it into both A and B before continuing. Do not keep the present state where a dormant module is listed as trainable.

Because the optimizer scope changes, the bounded A1 smoke must be rerun under the corrected frozen scope. The existing 100-step run remains useful preliminary evidence but is not the final A1 closure run.
