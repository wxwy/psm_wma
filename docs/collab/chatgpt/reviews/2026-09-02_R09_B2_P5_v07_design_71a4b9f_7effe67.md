## HIGH findings

### HIGH-1 — source root / run root / staging root contract still incomplete

v0.7 correctly separates four identities:
- production_source_root
- p4_run_root
- p4_staging_root
- evidence/exporter roots

However P5 implementation contract still needs an exact authoritative binding for how these are discovered from P4-v4 evidence and how child sys.path is reconstructed. The P4-v4 request/result/verification triple must be the only source of truth.

Required:
- exact schema for all path identities;
- exact SHA binding between request/result/verification;
- explicit child cwd/source/staging relationship;
- no fallback to legacy P4 v2 records.

### HIGH-2 — P4-v4 preflight schema must be treated as a prerequisite Gate

v0.7 defines:
request.json
result.json
verification.json
under p4_execution_preflight_v4.

This is the correct direction, but P5 cannot be implemented until this becomes an independently approved P4-v4 artifact contract with:
- fixed schema;
- producer/verifier ownership;
- canonical discovery rules;
- digest rules;
- PASS/BLOCKED semantics.

P5 verifier must not invent or infer missing preflight fields.

### HIGH-3 — loader environment/sys.path contract needs executable grammar

v0.7 improves the empty-environment and staging authority model, but implementation needs exact grammar for:
- inherited environment keys;
- forbidden environment keys;
- sys.path ordering;
- stdlib/lib-dynload identity;
- staged payload ordering.

The contract must fail if cwd/source/site-packages/.pth/ambient paths enter import authority.

## MEDIUM findings

### MEDIUM-1 — post-preflight run_root roster needs exact schema

P5 only reads P4-created run/staging state. Therefore define the immutable roster:
- allowed files/directories;
- readonly expectation;
- forbidden runtime outputs before export;
- mutation detection.

## Positive observations

- Correctly removed the v0.6 source/staging ambiguity.
- Correctly preserved verified lexical loader, request SHA, bootstrap binding, and no-export execution boundary.
- Correctly kept P5 export/compose/GPU/training unauthorized.
