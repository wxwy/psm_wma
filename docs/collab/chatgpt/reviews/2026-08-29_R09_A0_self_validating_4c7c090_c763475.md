## HIGH-2 — carried Local presence is lost across an all-masked second segment

Current backend implementation in submodule `c763475` does:

```python
present = mask.bool().any(dim=1)
...
return state[:, None] * present[:, None, None], state, present
```

This makes `present` depend only on **new valid evidence in the current replay call**, not on whether `state_in` already contains persistent Local memory.

Consider a legal split:

```text
full window mask: [True, True, False, False]
split after timestep 2

segment 1:
  valid evidence -> state becomes persistent/nonzero
  present = true

segment 2:
  state_in = carried segment-1 state
  mask = [False, False]
```

Numerical state is correctly preserved by masked updates, but current code yields:

```text
present = false
token = zero
```

while full-window replay yields:

```text
present = true
token = carried state/readout
```

Therefore the runbook's frozen requirement:

```text
full-window vs two-segment carry+detach
state AND token numerically equivalent
```

is not satisfied for arbitrary valid segment boundaries.

The current verifier misses this because every sample that has valid history also happens to have at least one valid timestep in segment 2.

### Required fix

The persistent backend state contract must carry presence/initialization semantics across segments, not only the latent tensor.

Equivalent designs are acceptable, e.g.:

```text
BackendState:
  latent
  present[B]
```

or an explicit `present_in` carried with `state_in`.

Required semantics:

- zero-start + all-mask full window -> absent;
- once valid evidence has established Local state, a later all-mask segment does **not** erase presence;
- explicit episode/sample reset clears both latent state and presence;
- masked timesteps do not create presence by themselves.

Add a hard regression where:

```text
valid evidence exists only in segment 1
segment 2 is entirely masked
```

and require full-window vs segmented equality for:

- final state;
- final token;
- final `local_present`.

This is the key remaining A0 algorithm-contract issue.

Meta-init verifies initialized parameter finiteness, but the artifact still lacks an explicit hard assertion that the normal A0 execution has finite:

### Masked-step inertness

Current test perturbs timestep 1 and only checks samples whose timestep 1 is masked. It includes one useful partially-valid sample, so the basic idea is accepted.

A stronger and simpler contract test is to perturb **all masked entries** and require final state/token/present to remain unchanged.
