# R09-B2 P2 non-mutating capture plan re-review — root b804855 / submodule e424e24

## Verdict

**APPROVE_TO_IMPLEMENT_B2_P2**

Scope is limited to the P2 implementation requested in the resubmission. This is **not** authorization for model/GPU/runtime capture, training, B2-T, P3-P5, eval/inference/closed-loop, SR, or backend freeze.

## Review

The three previous design blockers are closed:

1. **No canonical second forward** — CLOSED. The plan now explicitly forbids a second forward through the canonical training model or canonical Local runtime. Normal/Zero/Shuffle must run only on a pure/stateless helper or explicitly isolated functional/cloned module/state path, using detached already-produced features and clones. Canonical hooks/counters/buffers must not be touched.

2. **RNG isolation including exception paths** — CLOSED. CPU/CUDA RNG states must be saved on entry and restored unconditionally in `finally`; a failure may be written only after restoration. The implementation tests must include RNG consumption followed by an exception and prove bitwise restoration.

3. **Cursor/runtime-state provenance** — CLOSED. Cursor evidence is restricted to immutable P1 metadata already attached to the consumed batch (`b2_stream_ordinal`, epoch, microbatch metadata); live dataloader iterator inspection/advancement is forbidden. Runtime-state hashing covers the frozen five-member TTT state and the complete recurrent backend state representation.

The additional hardening is also appropriate: before/after hashes now include model parameters **and buffers**, optimizer, scheduler, CPU/CUDA RNG, immutable batch ordinal metadata, and complete Local runtime state; mutation or malformed/unsupported inputs must fail closed.

## Implementation acceptance conditions

The implementation submitted for closure must machine-test at least:
- Normal/Zero/Shuffle operate on detached clones only;
- canonical model/runtime second-forward path is impossible or rejected;
- parameter and buffer mutation is detected;
- optimizer and scheduler mutation is detected;
- complete recurrent / TTT runtime-state mutation is detected;
- batch ordinal/epoch/microbatch metadata mutation is detected;
- CPU/CUDA RNG is exactly restored on success and exception paths;
- unsupported mode and malformed Local payload fail closed;
- non-history input/packing/mRoPE invariants are bitwise identical across three modes;
- future/action sensitivity is recorded without changing canonical training state.

Root/submodule/Gitlink provenance and tool/source SHA256 must be included in the machine-readable P2 artifact/verifier at closure.

## Authorization boundary

Allowed now: minimal P2 callback/pure helper, CPU unit tests, root verifier and CPU-only artifact generation required to prove the isolation contract.

Still prohibited: model/VAE/optimizer loading for a real training run, GPU/runtime capture, optimizer updates, B2-T, P3-P5, eval/inference/closed-loop, SR, multi-GPU, long training, or backend selection.
