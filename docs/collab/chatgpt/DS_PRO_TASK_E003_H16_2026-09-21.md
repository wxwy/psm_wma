## Frozen E003 semantics

E003 is a bounded recent-history control:

- canonical evidence: `visual96 + executed_action10`
- history horizon: `H=16`
- backend: recurrent
- every policy query replays the retained history from zero recurrent state
- no GRU hidden state persists across policy queries
- no TTT fast weight is used
- Local interface is fixed at exactly `1 x 32`
- all R09-A1 / B1-TTT / B-TTT / ACTIVE routes are disabled

Interpretation boundary:

- `H=16` is numerically equal to `ttt_tbptt_steps=16`, but Local TTT is NOT a 16-step memory.
- Local TTT carries fast-weight state across detached segments for the full episode.
- `ttt_tbptt_steps` only bounds the training graph.
- E003 is therefore a one-segment-scale bounded recent-history control, NOT a persistence-only ablation.

Do not change H, Local dim, optimizer scope, training steps, model structure, or route semantics during this experiment without an explicit new decision.
