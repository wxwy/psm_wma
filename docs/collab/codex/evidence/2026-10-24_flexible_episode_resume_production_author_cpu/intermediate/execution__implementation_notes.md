verify_inputs(job,phase) phases: pre_model_load, post_model_load, pre_commit. Parent supplies actual model/config/task metadata checks. The helper does not substitute path strings for these checks. Startup/episode/task budgets, global cancellation, kill/reap of only owned groups and actual cleanup evidence are retained. Both process groups close before finish_attempt validates/commits COMPLETE. Every infrastructure/cleanup/catalog callback error remains in returned errors even if source coverage is full. Primary and secondary cleanup errors are retained separately. Initialization/partial thread-start failures also cancel/join started Workers.

Return: completed, source_attempts, jobs, errors, cancelled. source_attempts/jobs include started failures for Parent to re-scan valid closed prefixes; no failed batch prefix is reclassified as whole-source COMPLETE by this helper. Pre-reserved, unexecuted sources remain durable pending RUNNING reservations and receive not_executed error entries; they never count as completed outcomes. A callback error AFTER native COMPLETE preserves that truthful native marker, but remains an invocation error and can never report successful overall execution.
